# Project rules
- Keep SCARLET presentation in the main screen and shared global semantic tokens; preserve the existing endpoint service contract to avoid changing integrations during visual work.
- Render the full-screen neural field as an animated canvas visualization of interface activity with density and pause controls, never as evidence of service connectivity; report only measured visual telemetry.
- Unsupported reference navigation remains disabled until a real integration exists, so no view implies fabricated capabilities.
